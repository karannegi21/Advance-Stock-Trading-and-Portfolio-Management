# 2-Minute Demo Script

1. Open frontend, register/login as demo user.
2. Browse Market, show live prices updating.
3. Open StockDetail for RELIANCE, show candlestick chart.
4. Place MARKET buy order for 10 shares.
5. Portfolio shows holdings and P&L.
6. Analytics shows metrics and equity curve (create snapshot).
7. Watchlist add TCS.
8. Leaderboard shows ranking.
9. Admin panel: pause/resume/reset simulator.
10. Logout.
